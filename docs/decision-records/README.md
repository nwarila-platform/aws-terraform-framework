# Architecture Decision Records

This directory contains the Architecture Decision Record (ADR) index for this
repository. Repo-specific ADRs will be added here when local decisions are
recorded.

ADRs are organized into two scopes per
[org ADR-0001](https://github.com/nwarila-platform/.github/blob/main/docs/decision-records/0001-use-architecture-decision-records.md):

- `org/` — byte-identical mirrors of org-baseline ADRs when this repository mirrors one.
- `repo/` — repository-specific ADRs when this repository records local decisions.

When this repo gains its first decision, copy the org ADR-0001 file as
the ADR template and place new entries in `repo/NNNN-short-kebab-title.md`.
